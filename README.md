# ريمواذكار — Remo Azkar

تطبيق أذكار وقرآن كامل **يعمل بدون إنترنت**، ويعتمد كليًا على **قراءة الروبوت للنصوص** (تحويل النص إلى كلام عربي فصيح) بدلًا من ملفات التلاوة المسجّلة.

> **لا يحتوي التطبيق على أي تلاوات صوتية مسجّلة** (لا العفاسي ولا غيره). كل نص في التطبيق قابل للنقر ليقرأه محرّك النطق العربي في الجهاز بصوت واضح وفصحى.

---

## المحتوى الكامل

| المحتوى | التفاصيل |
|---|---|
| القرآن الكريم | **114 سورة** و**6236 آية** كاملة، مع بيانات الجزء والصفحة والحزب لكل آية (`assets/quran.json` — 2.4MB) |
| حصن المسلم | **132 بابًا** و**291 ذكرًا** مع عدد التكرارات والحواشي (`assets/hisn.json` — 111KB) |
| التقويم الهجري | تحويل دقيق (خوارزمية كويتية) + 12 مناسبة إسلامية مع عدّاد الأيام المتبقية |
| الأذكار الخاصة | إضافة/تعديل/حذف أذكار المستخدم مع عدد تكرار مخصّص |
| المسبحة | عدّاد مع حفظ الإجمالي في DataStore |
| التذكيرات | مواعيد دقيقة عبر AlarmManager + إعادة الجدولة بعد إعادة التشغيل |
| المفضلة | نجوم على الآيات والأذكار والأذكار الخاصة |
| البحث | بحث موحّد في القرآن والأذكار بتطبيع عربي كامل (بدون تشكيل) |

## الميزات الجديدة غير الموجودة في التطبيقات المشابهة

1. **قراءة الروبوت لكل شيء**: أي نص في التطبيق (آية، ذكر، حاشية، عنوان باب، نتيجة بحث) قابل للنقر ليُقرأ بصوت فصيح — مع تقسيم ذكي للنصوص الطويلة (حتى 2200 حرف على حدود الجُمل) وتنظيف التشكيل قبل النطق لتفادي الأخطاء.
2. **المساعد الصوتي الحر**: اكتب أو الصق أي نص عربي (دعاء، خطبة، نص منسوخ) ليقرأه الروبوت — التطبيق ليس محدودًا بمحتواه.
3. **خطة الورد اليومي**: خطة روحية يومية (ورد قرآن، أذكار صباح/مساء، استغفار، صلاة على النبي، الكهف يوم الجمعة) مع نسبة إنجاز وسلسلة أيام متتالية (Streak) تُصفَّر يوميًا وتبقى السلسلة محفوظة.
4. **التقويم الهجري بالمناسبات**: عدّاد "بعد N يوم" لرمضان وعرفة وعاشوراء وغيرها.
5. **تذكيرات ذكية تلقائية**: تذكير بسورة الكهف كل جمعة 9:00 ص، وسورة الملك كل ليلة 9:30 م — بدون أي إعداد من المستخدم.
6. **مشاركة أي ذكر أو آية** كنص عبر أي تطبيق.
7. **تتبّع التكرار داخل صفحة الذكر**: عدّاد لكل ذكر مع شريط تقدّم حتى الوصول للعدد المطلوب.
8. **بحث عربي مُطبَّع**: يتجاهل التشكيل وأشكال الألف والياء والتاء المربوطة، فيجد النتيجة مهما كتبت.

## البنية التقنية

- **Kotlin + Jetpack Compose + Material 3**
- `QuranRepository` / `HisnRepository`: تحميل JSON من `assets` في الذاكرة (بدون Room، بدون إنترنت)
- `TtsManager`: كائن واحد (singleton) لمحرّك النطق، بحالة Compose (`isSpeaking`, `isReady`, `lastError`) وشريط تحكّم عائم `TtsMiniBar` يظهر في كل الشاشات
- `ReminderScheduler` + `ReminderReceiver` + `BootReceiver`: جدولة دقيقة وإعادة جدولة بعد الإقلاع
- `NotificationHelper`: قناتان (تذكيرات / يومية) مع دعم Android 13+
- `PreferencesManager` (DataStore): الوضع الليلي، المفضلة، سرعة ونبرة الصوت، حجم الخط
- `DailyWirdStore` / `CustomAzkarStore` / `ReminderScheduler`: تخزين JSON في SharedPreferences

### الصلاحيات
`INTERNET`, `ACCESS_NETWORK_STATE`, `POST_NOTIFICATIONS`, `RECEIVE_BOOT_COMPLETED`, `SCHEDULE_EXACT_ALARM`, `USE_EXACT_ALARM`, `WAKE_LOCK`, `FOREGROUND_SERVICE`, `VIBRATE`

## البناء

```bash
./gradlew assembleRelease
```

التوقيع يُقرأ من متغيّرات البيئة: `KEYSTORE_PATH`, `STORE_PASSWORD`, `KEY_PASSWORD` (alias: `upload`).

يوجد Workflow في `.github/workflows/` باسم **Build Android Release APK** يفكّ ترميز `KEYSTORE_BASE64` من أسرار المستودع ويبني APK موقّعًا ويرفعه كـ artifact باسم `release-apk`.
