# ريمواذكار (Remo Athkar) 📿📖

تطبيق إسلامي شامل ومتطور يجمع بين الأذكار والأدعية اليومية، القرآن الكريم، المسبحة الإلكترونية، والأذكار الصوتية، مع روبوت ذكاء اصطناعي صوتي يعمل بدون إنترنت.

برمجة وتطوير المطور: **محمد الحزمي**  
جميع الحقوق محفوظة للمطور 2026 ©

---

## ✨ المميزات الرئيسية
- **القرآن الكريم كاملاً**: نصوص القرآن الكريم وسوره مع قاعدة بيانات محلية (Room Database) وميزة البحث السريع والانتقال للصفحات.
- **الأذكار والأدعية وحصن المسلم**: أذكار الصباح والمساء، أذكار النوم، أدعية قرآنية ونبوية، والرقية الشرعية مع عدادات تفاعلية ونظام المفضلة (Favorites).
- **المسبحة الإلكترونية المتطورة**: حلقة تقدم تفاعلية مع دعم الاهتزاز عند اللمس، اختيار الأهداف (33، 100، 500، 1000)، وزر إعادة الضبط.
- **التلاوات والأذكار الصوتية**: مشغل صوتي مدمج مع شريط تمرير تفاعلي (Slider) لتقديم وترجيع الصوت بالأصبع.
- **روبوت الذكاء الاصطناعي الصوتي (بدون إنترنت)**: نطق وقراءة الأذكار بصوت عربي فصيح وطبيعي مع إمكانية تعديل سرعة ونبرة الصوت.
- **الرفيق الروحي**: اقتراحات أذكار وأدعية مخصصة بحسب الحالة النفسية والشعورية للمستخدم.
- **نظام التنبيهات التلقائية (WorkManager)**: إشعارات دورية منتظمة للأذكار على شاشة القفل والخلفية مع خيارات مخصصة للوقت والتكرار.
- **تخصيص القراءة**: التحكم في حجم الخط (صغير، متوسط، كبير) والوضع الداكن (Night Mode).
